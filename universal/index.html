Dashboard Universal

Arraste um arquivo aqui ou clique para escolher

CSV, Excel (XLSX), Word (DOCX) e PDF com tabelas, JSON, GeoJSON, KML ou KMZ. Os dados do arquivo são processados no seu computador e não são enviados a nenhum servidor.

Acessos externos que existem: o mapa de fundo (Esri) baixa imagens de mapa e revela a região que você está vendo — dá para escolher “Sem mapa de fundo”; e o programa instalado consulta o GitHub para ver se há atualização do painel — dá para desligar em Ajuda.

    Gerar HTML para compartilhar

    Cria um único arquivo .html que qualquer pessoa abre no navegador, sem instalar nada. Ele abre exatamente como você está vendo agora (filtros, tipos de gráfico e gráficos removidos).

    Atenção: os dados da tabela vão dentro do arquivo. Quem receber poderá ver todas as linhas; não inclua informações pessoais ou restritas.
